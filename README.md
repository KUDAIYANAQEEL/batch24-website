# Batch 24 — Official School Batch Website

A responsive starter website for a school batch, built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — colors, layout, typography, and responsive styling
- `script.js` — mobile navigation and automatic footer year

## Run locally
1. Extract `batch24_website.zip`.
2. Open the `batch24_website` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Edit the placeholder committee members, email, social links, and announcements.

## Before publishing
- Confirm whether “Batch 24” and “2024” are the correct public names.
- Replace placeholder committee details and contact links.
- Replace example announcements with verified information.
- Only upload photos and personal details with permission.
- This is a front-end template. It does not include a backend, login, database, or working message-submission form.
- Google Fonts requires an internet connection; fallback fonts are included.
